# Locket SDK

SDK TypeScript cho Node.js, mã nguồn nằm trong [`dome/`](dome/README_VI.md).

Yêu cầu Node.js 22+ và FFmpeg trên `PATH` (hoặc biến `FFMPEG_PATH`).

```powershell
npm ci
npm run typecheck
npm test
npm run build
npm run demo -- --help
```

Xem [hướng dẫn tích hợp](dome/docs/INTEGRATION_VI.md), [danh sách API](dome/docs/FEATURES_VI.md) và [ghi chú chuyển đổi](dome/docs/MIGRATION.md).
